# Akshitha R - Personal Portfolio

A professional and responsive personal portfolio website designed to showcase my projects, skills, education, and internship experiences. Built using modern web technologies to be visually appealing, user-friendly, and fully responsive across all devices.

## 🚀 Features

- **Responsive Design**: Adapts seamlessly to desktops, tablets, and mobile devices.
- **Dynamic Navigation**: Sticky top navigation on desktop and a compact fixed section bar on mobile, with smooth scrolling.
- **Developer-first visual design**: Original terminal-inspired hero, full-stack architecture flow, and a tailored technology strip.
- **Project Showcase**: Highlights NovaCart, the Generative AI sensor dashboard, and the College Conference Website, with category filters, source links, and a dashboard screenshot.
- **Modern Interactions**: Scroll progress indicator, animated section reveals, and a back-to-top control.
- **Experience & Education**: Covers my full-stack developer role at Conprg Technologies and my B.E. in Electronics and Communication Engineering.
- **Skills Section**: Organized skills across React, TypeScript, ASP.NET Core, C#, PostgreSQL, and related tools.
- **Updated Resume**: Direct link to open my current PDF resume.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure
- **CSS3**: Custom styling, animations, flexbox, grid, and responsive layouts
- **JavaScript (ES6+)**: Interactive elements, scroll spying, and smooth transitions
- **Font Awesome**: Icons for UI elements
- **Google Fonts**: Space Grotesk with IBM Plex Mono for code details

## 💻 Local Installation & Setup

To view this portfolio locally on your machine, simply follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Akshi-hub23/Portfolio_resume.git
   ```

2. **Navigate to the directory:**
   ```bash
   cd Portfolio_resume
   ```

3. **Open the project:**
   Simply open the `index.html` file in your preferred web browser, or use a local development server like VS Code's "Live Server" extension for a better development experience.

## 📁 Repository Structure

- `index.html`: The main HTML document containing the structure of the portfolio.
- `style.css`: The stylesheet containing all styling rules and responsive media queries.
- `script.js`: The JavaScript file handling navigation, animations, and interactive elements.
- `Akshitha_Resume-1.pdf`: Current resume, linked from the portfolio.
- `assets/generative-ai-dashboard-overview.jpeg`: Screenshot from the live Generative AI Dashboard.
